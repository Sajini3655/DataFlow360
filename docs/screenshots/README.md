# Screenshot capture checklist

Actual UI inspection was available during development, including the
Business Intelligence page. The available browser capture interface returns
images to the chat but does not provide a supported way to save captures into
this repository. No screenshot files are included rather than fabricating or
reconstructing screenshots.

When a local browser automation tool with screenshot file output is available,
capture the running application at its actual local URL and save reviewed,
redacted images here:

- [ ] Overview
- [ ] Sources
- [ ] Data Quality
- [ ] Medallion
- [ ] Star Schema
- [ ] Analytics
- [ ] Inventory
- [ ] Processing
- [ ] Airflow
- [ ] Cloud Integration
- [ ] Business Intelligence

Before capture, use synthetic data only and verify that no credentials,
tokens, personal information, or internal connection details are visible.
Do not create a screenshot of a page that is not running or verified.
